Quick-Fire Sanity Checks · Pre-Test

  • == on objects = reference identity. Always .equals() for value.
  • String immutable; StringBuilder for loops. Concat in loop = O(n²) trap.
  • Primitives on stack / inline; objects always heap. References are not pointers.
  • Override equals() ⇒ MUST override hashCode(). Non-negotiable.
  • Scanner.nextInt() + nextLine() = empty-string bug. BufferedReader for speed.
  • char + int = int. Cast back: (char)(c + 1).
  • Arrays covariant (runtime check), generics invariant (compile-time safe).
  • ArrayList<Integer> ≈ 6× memory of int[]. Use primitive arrays in hot paths.
  • HashMap is not ordered (use LinkedHashMap) and not sorted (use TreeMap).
  • try-with-resources over finally. finalize() is dead.
  • static fields outlive instances — common leak vector.
  • Pre-size ArrayList, HashMap, StringBuilder when N is known. Resizes are O(n) wasted work.
